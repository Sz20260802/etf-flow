# ETF 资金流分析终端

免费数据源驱动的 A 股 ETF 资金流分析系统（Streamlit + SQLite）。

## 功能模块

| 页面 | 说明 |
|---|---|
| 全市场走势 | 全市场 ETF 单日净流入、累计曲线、8 档周期对比、拥挤度/轮动速度 |
| 份额雷达 | 全市场 ETF 分周期净流入排行，四象限标签（追高/逃顶/逃离/追高吃套） |
| 板块轮动 | 16 大板块资金桑基图 + 规则化解读 |
| β压强 | ETF 份额变动穿透到个股的净压强排行（需持仓权重 + 连续份额） |
| 穿透历史 | 单只个股的逐日穿透变动回放（三档口径，逐日标注覆盖率） |
| ETF VIX | 期权 QVIX 恐慌指数 ×4 + 宽基指数 PE-TTM 估值水位 |

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 每日更新

```bash
python3 daily_update.py          # 完整增量更新（幂等，可重复跑）
python3 daily_update.py --check  # 只检查是否需要更新
```

云端部署时实例唤醒后自动检测并后台补更（无需人工干预）。

## 数据口径

- 单日净流入（亿元）=（当日份额 − 前日份额）× 当日净值 ÷ 1e8
- 份额日度历史：免费源无历史回填，部署后逐日积累（第 2 个交易日起出数）
- 穿透变动为**估算股数**，不等同于现货成交或真实持仓变更（详见 docs/穿透口径定义.md）
- 板块分类规则：docs/板块分类口径表.md
